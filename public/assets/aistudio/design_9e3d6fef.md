# Magentify Mini — Design System

> 거래 내역(CSV/XLSX)에서 연락이 뜸해진 거래처를 감지하고, 맞춤형 연락 문안까지 도와주는 로컬 에이전트.
> 이 문서는 [ztd-charts 테마](https://charts.ztd.app/docs/docs/theme/)의 `--ztd-*` 토큰을 기반으로, **SaaS 업무 도구**와 **일반 사용자 기준의 높은 가독성**에 맞춰 확장한 디자인 가이드입니다.

---

## 1. 디자인 원칙

| # | 원칙 | 의미 |
|---|------|------|
| 1 | **한 화면, 한 목적** | 화면마다 "지금 할 일" 하나만 크게 보여준다. |
| 2 | **읽기 편하게, 넉넉하게** | 본문 16px 이상, 높은 대비, 충분한 터치 영역. |
| 3 | **색만으로 말하지 않기** | 상태는 항상 색 + 아이콘 + 텍스트 라벨을 함께 쓴다. |
| 4 | **결과부터, 설명은 뒤에** | 요약 → 목록 → 상세 순서. 전문 용어 대신 쉬운 말. |
| 5 | **실수해도 안전하게** | 되돌리기·미리보기·확인 단계를 기본 제공. |
| 6 | **내 컴퓨터 안에서** | "데이터는 내 PC 밖으로 나가지 않아요"를 UI에서 계속 안심시킨다. (로컬 에이전트의 핵심 가치) |

### 2.2 가독성 확장 규칙 (Magentify 전용)

ztd-charts 문서에 따르면 `dim`은 카드 위에서 라이트 1.97:1로 **WCAG AA 미달**입니다. 그래서 다음 규칙을 강제합니다.

- ✅ 모든 글자는 `ink`(본문/제목) 또는 `muted`(보조)만 사용. `dim`은 선·축에만.
- ✅ 강조색을 글자로 쓸 때는 반드시 `accentText`(`#006DA8`). `accent`(`#0B8FD8`)는 도형·배경 전용.
- ✅ 중요 정보에는 `ink`, `muted`는 부가 설명에만 사용.
- ✅ 12px 이하 텍스트 금지. `muted` 텍스트도 최소 14px.

### 2.3 의미(Semantic) 색상 — 거래처 상태

| 상태 | 라벨 | 색상 토큰 | 아이콘 | 설명 |
|------|------|-----------|--------|------|
| 긴급 | `연락 필요` | `accent2` (`#D8488C`) | ⚠ 경고 삼각형 | 오랫동안 거래·연락 없음 |
| 주의 | `뜸해지는 중` | `neutralStrong` + `ink` 텍스트 | ◔ 시계 | 평소보다 주기가 길어짐 |
| 양호 | `정상` | `accent3` (`#659815`) | ✓ 체크 | 최근 거래 있음 |
| 정보 | `새로 추가됨` | `accent` + `tint` 배경 | ● 점 | 신규·안내 |

> 배지 글자색은 항상 `ink`로 두고, 색은 **왼쪽 아이콘과 배경 tint**에만 사용합니다. (색 자체를 글자로 쓰지 않아 대비 문제를 피함)

### 2.5 다크 모드 (선택 제공)

- 기본은 **라이트**. 설정에서 "어두운 화면"으로 전환 가능하게 하고, OS 설정(`prefers-color-scheme`)을 최초 1회만 따른다.
- ztd-charts는 `ThemeProvider` 없이 쓰면 다크로 그려지므로, 앱 루트에서 **반드시 `theme="light"`를 명시**한다.

## 3. 타이포그래피

**폰트**: Pretendard Variable (ztd-charts 권장 폰트, 한글 가독성 우수). 미설치 시 시스템 폰트 폴백.

| 역할 | 크기 | 굵기 | 행간 | 용도 |
|------|------|------|------|------|
| Display | 40px / 2.5rem | 700 | 1.25 | 랜딩 헤드라인 |
| H1 | 30px / 1.875rem | 700 | 1.3 | 페이지 제목 |
| H2 | 24px / 1.5rem | 700 | 1.35 | 섹션 제목 |
| H3 | 20px / 1.25rem | 600 | 1.4 | 카드 제목 |
| **Body (기본)** | **16px / 1rem** | 400 | **1.6** | 본문, 표 셀 |
| Body-large | 18px / 1.125rem | 400 | 1.7 | 핵심 안내문, 문안 미리보기 |
| Label | 14px / 0.875rem | 600 | 1.5 | 폼 라벨, 버튼, 배지 |
| Caption | 14px / 0.875rem | 400 | 1.5 | 보조 설명 (`muted`) |
| KPI 숫자 | 40px / 2.5rem | 700 | 1.1 | 요약 수치 (`tabular-nums`) |

규칙:
- **최소 글자 크기 14px.** 그 아래는 쓰지 않는다.
- 한 줄 길이 **한글 기준 40~50자**(최대 폭 약 `42em`)로 제한.
- `font-variant-numeric: tabular-nums` — 금액·날짜 자리 정렬.
- 굵기 대비로 위계 표현(400 ↔ 700). 300 이하 얇은 굵기 금지.
- 설정에서 글자 크기 선택(기본 16px / 크게 18px)을 선택 기능으로 제공 (`--mg-text-base` 변경).
- 숫자 서식은 한국 단위 사용: `formatCompact` → `1.2만`, `3.4억` (ztd-charts `locale="ko-KR"`).

## 4. 간격·레이아웃·형태

- **8px 그리드.** 카드 내부 패딩 24px (모바일 16px).
- **카드 반경 18px** (`--ztd-radius`) — ztd-charts와 동일하게 통일해 차트 카드와 일반 카드가 한 덩어리로 보이게 한다.
- 버튼·입력창 반경 12px, 배지 999px(pill), 작은 마크 4px.
- 보더 1px `--ztd-line`, 그림자는 아주 약하게(`--mg-shadow-card`).
- 콘텐츠 최대 폭 **1120px**, 본문 읽기 영역 **720px**.
- 브레이크포인트: 모바일 ≤ 640 / 태블릿 641–1024 / 데스크톱 ≥ 1025.
- 정보 밀도는 **중간**. 한 화면에 핵심 카드 4개 이하로 유지한다.

## 5. 정보 구조 (IA) & 핵심 사용자 흐름

SaaS 온보딩 → 핵심 가치(Aha) 도달까지 **3단계 이내**로 줄인다.

```
① 파일 올리기  →  ② 뜸해진 거래처 확인  →  ③ 연락 문안 고르고 복사/전송
```

### 5.1 내비게이션

데스크톱: 상단 가로 탭 (아이콘 + 텍스트, 최대 4개). 모바일: 하단 고정 탭 바 (아이콘 + 라벨, 높이 64px).

| 메뉴 | 목적 |
|------|------|
| 홈 | 오늘 연락할 거래처 요약 |
| 거래처 | 전체 목록·검색·필터 |
| 문안 | 저장된 문안·템플릿 |
| 설정 | 글자 크기, 기준 기간, 데이터 관리 |

- 아이콘만 쓰지 않는다. **항상 텍스트 라벨 병기.**
- 현재 위치는 색 + 굵기 + 하단 3px 밑줄로 이중 표시.
- 햄버거 메뉴·중첩 드롭다운 지양.

### 5.2 화면 구성

**A. 시작/업로드 화면**
1. 큰 안내 제목: "거래 내역 파일을 올려 주세요"
2. 점선 드롭존(높이 최소 200px) + 큼직한 `파일 선택하기` 버튼 — 드래그만 가능하게 하지 않는다.
3. 지원 형식 표시: `CSV · XLSX`
4. 안심 문구(자물쇠 아이콘): "파일은 이 컴퓨터 안에서만 처리돼요."
5. 하단 링크: `샘플 파일로 먼저 체험하기` (공모전 심사 시 즉시 체험 가능)

**B. 홈(대시보드)**
1. 인사 + 한 줄 요약: "연락이 뜸해진 거래처가 **12곳** 있어요."
2. KPI 카드 3개 (연락 필요 / 뜸해지는 중 / 정상)
3. 우선순위 목록(상위 5곳) + `전체 보기`
4. 거래 흐름 차트 1개 (아래 §7)

**C. 거래처 목록**
- 검색창(상단 고정), 필터 칩(전체/연락 필요/뜸해지는 중/정상), 정렬 선택
- 표(데스크톱) ↔ 카드 리스트(모바일) 자동 전환
- 행 전체가 클릭 영역

**D. 거래처 상세 + 문안**
- 좌: 거래 이력 요약·마지막 거래일·평균 주기
- 우(모바일은 아래): **문안 3종**(정중하게 / 친근하게 / 간단하게) 탭 → 미리보기 → `복사하기` / `직접 고치기`

## 6. 컴포넌트 명세

### 6.1 버튼

| 종류 | 배경 | 글자 | 용도 |
|------|------|------|------|
| Primary | `--ztd-accent-text` (#006DA8) | `#FFFFFF` | 화면당 1개: 파일 올리기, 복사하기 |
| Secondary | `--ztd-panel` + 2px `--ztd-ink` 테두리 | `--ztd-ink` | 보조 동작 |
| Ghost | 투명 | `--ztd-accent-text` + 밑줄 | 텍스트 링크형 |
| Danger | `--ztd-accent2` 배경 계열 진하게 | `#FFFFFF` | 데이터 삭제 (확인 단계 필수) |

- 높이 **최소 44px**(기본 48px), 좌우 패딩 20px, 글자 16px/600.
- Primary는 `accent`(밝은 하늘색) 대신 **`accentText`(#006DA8)를 배경으로** 사용해 흰 글자와의 대비를 확보.
- 호버: 명도 ↓ 8%. 눌림: translateY(1px). 비활성: 투명도 대신 `neutral` 배경 + `muted` 글자 + 이유 문구 제공.
- 버튼 라벨은 **동사로 구체적으로**: "확인" ✕ → "문안 복사하기" ○

### 6.2 입력창·폼

- 높이 48px, 글자 16px, 테두리 1px `--ztd-neutral-strong`, 포커스 시 `--ztd-accent-text` 2px 링 + `lift` 배경.
- **라벨은 입력창 위에 항상 표시** (placeholder를 라벨로 쓰지 않음).
- 도움말은 입력창 아래 `muted` 16px, 오류는 `⚠ + 문장`으로 구체적으로: "날짜 열을 찾지 못했어요. 첫 줄에 '거래일' 같은 제목이 있는지 확인해 주세요."
- 필수 표시는 `(필수)` 텍스트로. 별표(*)만 쓰지 않는다.

### 6.3 파일 드롭존

- 점선 2px `--ztd-neutral-strong`, 반경 18px, 배경 `--ztd-lift`.
- 드래그 오버 시 배경 `--ztd-tint` + 테두리 `--ztd-accent-text` 실선.
- 업로드 중: 진행률 바(높이 12px) + "파일을 읽는 중… 60%" 텍스트.
- 완료: ✓ 아이콘 + "거래 1,240건을 불러왔어요" + 다음 단계 Primary 버튼.

### 6.4 KPI 카드 (ztd-charts `StatCard` 활용)

- 숫자 40px bold, 아래 라벨 16px, 전월 대비 변화는 `▲ 3곳 증가`처럼 **화살표 + 텍스트**.
- 카드 하나당 숫자 하나. 설명 한 줄(최대 30자).

### 6.5 거래처 목록 / 표

- 행 높이 최소 56px, 셀 패딩 12px 16px, 지브라 대신 1px 구분선.
- 열: 거래처명(굵게) · 마지막 거래일 · 경과일 · 상태 배지 · `문안 보기` 버튼.
- 헤더는 sticky, 정렬 가능 열에는 `▲▼` 아이콘 + `aria-sort`.
- 모바일: 카드형 — 거래처명 / 상태 배지 / "마지막 거래 47일 전" / 전체 폭 버튼.

### 6.6 상태 배지

- 높이 28px, 패딩 4px 12px, 글자 14px/600, `ink` 글자, 상태 색은 배경 tint + 왼쪽 아이콘.

### 6.7 문안 미리보기 패널

- 카드 배경 `--ztd-lift`, 글자 18px, 행간 1.7, 최대 폭 42em.
- 문안 3종은 **탭**(세그먼트 컨트롤)으로 전환, 선택된 탭은 `--ztd-tint` 배경 + 2px 밑줄 + 굵게.
- 하단 고정 액션: `복사하기`(Primary) · `직접 고치기`(Secondary).
- 복사 성공 시 토스트: "복사했어요. 메신저나 메일에 붙여넣으세요." (5초 유지, 닫기 버튼, `role="status"`).

### 6.7 알림·토스트·다이얼로그

- 토스트는 **최소 5초**, 사라지기 전에 닫기 버튼 제공. 중요한 결과는 토스트가 아닌 화면 내 배너로.
- 삭제·초기화는 모달 확인: 제목에 대상 명시("거래 데이터를 삭제할까요?"), 버튼은 `삭제하기` / `취소`(기본 포커스는 `취소`).

### 6.8 빈 상태 / 로딩 / 오류

- 빈 상태: 일러스트 대신 **큰 아이콘 + 한 문장 + 버튼 하나**. 예: "아직 올린 파일이 없어요 → [파일 올리기]".
- 로딩: 스켈레톤(카드 형태 유지), 3초 이상이면 진행 문구 표시.
- 오류: 원인 + 해결 방법 + 다시 시도 버튼. 기술 용어·에러 코드는 "자세히 보기" 안에 숨김.

## 7. 차트 가이드 (ztd-charts 적용)

### 7.1 설치 및 적용

```bash
npm i ztd-charts
```

```tsx
import { ThemeProvider, ChartCard, StatCard, BarChart, DonutChart } from "ztd-charts";

// 앱 루트: 라이트 테마 + 한국어 + 페인트(배경 적용)
<ThemeProvider
  theme="light"
  locale="ko-KR"
  paint
>
  <App />
</ThemeProvider>
```

Magentify 전용 토큰을 덮어쓰려면 CSS 변수만 바꾼다 (React 리렌더 없음):

```css
.magentify-report {
  --ztd-accent: #0B8FD8;
  --ztd-accent-text: #006DA8;
}
```

### 7.2 어떤 차트를 쓸까

| 목적 | 차트 | 비고 |
|------|------|------|
| 상태별 거래처 비율 | `DonutChart` | 항목 2~4개로 제한, 중앙에 총 거래처 수 |
| 월별 거래 흐름 | `LineChart` / `AreaChart` | 선 1~2개만. 비교 대상은 `neutral` |
| 거래처별 마지막 연락 경과일 | `BarChart` (가로) | 상위 10개, `highlight="max"` |
| 요약 수치 | `StatCard` | KPI 카드와 동일 스타일 |
| 거래 활동 달력 | `CalendarHeatmap` | 선택 사항 |

### 7.3 가독성 중심 차트 규칙

1. **차트 1개당 메시지 1개.** `ChartCard`의 `takeaway`(한 줄 결론)를 반드시 채운다. 예: `takeaway="지난 3개월간 거래가 줄었어요"`.
2. **강조는 하나만.** `highlight`로 가장 중요한 항목 1개만 `accent`, 나머지는 `neutral`.
3. **값 라벨 직접 표시** (`showLabels` 기본 true 유지). 범례를 찾아 눈을 오가지 않게 한다.
4. **툴팁에 의존하지 않기.** 모바일은 hover를 못 쓰므로 핵심 값은 화면에 상시 표기.
5. 차트 텍스트도 14px 이상으로 보이도록 `height`를 넉넉히(데스크톱 300px, 모바일 260px) 지정.
6. 색 구분이 필요하면 **패턴/직접 라벨**을 병행. 범례 항목은 색 + 이름 + 값.
7. 숫자 포맷: `format="compact"` + `locale="ko-KR"` → `1.2만`, `3.4억`. 금액은 `format="currency"`(KRW 자동).
8. 접근성: ztd-charts는 `role="img"`, 데이터 기반 설명, 숨은 데이터 표, 키보드 탐색(방향키/Home/End)을 기본 제공 → 제거하지 않는다. 필요 시 `ariaLabel`, `description`로 한국어 요약을 보강.
9. 모션: `reducedMotion="auto"` 유지(OS 설정 존중). 애니메이션은 `duration` 600~900ms, `replay` 버튼 제공.

### 7.4 예시

```tsx
<ChartCard
  number="01"
  title="거래처 상태"
  subtitle="전체 거래처 기준"
  takeaway="12곳에 먼저 연락해 보세요"
  level="basic"
  legend={[
    { label: "연락 필요", color: "accent" },
    { label: "뜸해지는 중", color: "ink" },
    { label: "정상", color: "neutral" },
  ]}
>
  <DonutChart
    data={[
      { status: "연락 필요", count: 12 },
      { status: "뜸해지는 중", count: 25 },
      { status: "정상", count: 63 },
    ]}
    label="status"
    value="count"
    highlight="연락 필요"
    format="integer"
    unit="곳"
    height={320}
  />
</ChartCard>
```

## 8. 접근성 체크리스트 (WCAG 2.2 AA 이상 목표)

**시각**
- [ ] 본문 텍스트 대비 4.5:1 이상 (`ink` 사용 시 충분), 큰 글자·UI 컴포넌트 3:1 이상
- [ ] `dim` 색을 글자에 쓰지 않았다
- [ ] 정보를 색만으로 전달하지 않았다 (아이콘 + 텍스트 병행)
- [ ] 브라우저 확대 200%에서도 가로 스크롤 없이 사용 가능
- [ ] (선택) 설정에서 글자 크기 조절 제공

**조작**
- [ ] 클릭/터치 영역 최소 44×44px, 인접 요소 간 8px 이상
- [ ] 모든 기능이 키보드만으로 가능 (Tab / Shift+Tab / Enter / Space / 방향키)
- [ ] 포커스 링 2px 이상, 항상 보임, 가려지지 않음
- [ ] 드래그 앤 드롭에는 반드시 버튼 대체 수단
- [ ] 시간 제한 없음 (세션 만료 시 사전 경고 + 연장)

**구조·스크린리더**
- [ ] 의미 있는 랜드마크(`header`, `nav`, `main`)와 제목 계층(h1→h2→h3)
- [ ] 아이콘 버튼에 `aria-label`, 장식 아이콘은 `aria-hidden`
- [ ] 폼 라벨 연결, 오류는 `aria-live`/`role="alert"`로 안내
- [ ] 표에 `<th scope>`와 캡션
- [ ] `<html lang="ko">`

**모션·인지**
- [ ] `prefers-reduced-motion` 존중
- [ ] 깜빡임·자동 재생 없음
- [ ] 용어는 쉬운 말 (예: "이탈 고객" → "연락이 뜸해진 거래처")
- [ ] 되돌리기/취소 경로 항상 존재

## 9. UX 라이팅 (한국어 톤 & 보이스)

- 존댓말 `~해요` 체: 따뜻하지만 가볍지 않게.
- 한 문장 40자 이내, 능동형, 긍정형.
- 영어·약어 최소화: `CSV/XLSX` 외에는 한글 우선.

| 상황 | ✕ 피하기 | ○ 이렇게 |
|------|----------|-----------|
| 업로드 성공 | Upload complete | 거래 1,240건을 불러왔어요 |
| 오류 | Error 400: Invalid format | 이 파일은 읽을 수 없어요. CSV 또는 XLSX 파일인지 확인해 주세요. |
| 빈 결과 | No results | 연락이 뜸해진 거래처가 없어요. 모두 최근에 거래했어요 👍 |
| 버튼 | 확인 / 제출 | 문안 복사하기 / 거래처 보기 |
| 프라이버시 | 로컬 처리 | 파일은 이 컴퓨터 안에서만 처리돼요 |

## 10. 모션

- 기본 전환 200ms `ease-out`, 차트 진입은 ztd-charts 스프링(과도 진동 없음) 유지.
- 의미 있는 모션만: 업로드 진행률, 차트 진입, 복사 완료 피드백.
- `@media (prefers-reduced-motion: reduce)` 에서는 모든 전환을 즉시 완료로.

## 11. SaaS UX 패턴

1. **온보딩**: 샘플 데이터로 즉시 체험 → 내 파일 업로드 (Aha 모먼트까지 60초 이내).
2. **점진적 공개**: 기본 화면은 단순하게, 고급 설정(기준 기간, 열 매핑)은 "자세히 설정" 접이식.
3. **신뢰 신호**: 로컬 처리 안내, 데이터 삭제 버튼, 개인정보 처리 안내를 설정과 업로드 화면에 상시 노출.
4. **다음 행동 제안**: 모든 결과 화면 끝에 "다음으로 할 일" Primary 버튼 1개.
5. **저장·복귀**: 마지막 작업 자동 저장, 재방문 시 "이어서 하기".
6. **도움말**: 우하단 `도움말` 버튼(텍스트 포함) → 짧은 가이드 3개, 전화/메일 문의 경로.
