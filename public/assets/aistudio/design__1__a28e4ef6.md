# design.md — Magentify Mini

> 거래 내역(CSV/XLSX)을 올리면 연락이 뜸해진 거래처를 감지하고, 맞춤 연락 문안까지 만들어 주는 로컬 에이전트.
> 이 문서는 **ztd-charts 테마 시스템**(`--ztd-*` 토큰)을 디자인 기반으로 삼아, 가장 짧은 동선으로 "업로드 → 감지 → 연락"까지 끝내는 UIUX를 정의합니다.

---

## 1. 디자인 원칙

| # | 원칙 | 의미 |
|---|------|------|
| 1 | **3클릭 안에 첫 결과** | 파일 업로드 → 자동 분석 → 뜸해진 거래처 목록. 설정 단계 없음 |
| 2 | **한 화면 한 목적** | 한 화면에는 하나의 주요 행동(CTA)만 둔다 |
| 3 | **하이라이트는 하나** | 차트·리스트 모두 가장 중요한 1개만 accent로 강조, 나머지는 neutral |
| 4 | **숫자보다 결론** | 차트 아래에 항상 한 줄 takeaway ("3곳이 90일 이상 무연락") |
| 5 | **로컬·안심** | "파일은 내 기기에서만 처리됩니다"를 업로드 영역에 상시 노출 |
| 6 | **일반 사용자 가독성** | 본문 16px 이상, 대비 AA(4.5:1) 이상, 터치 영역 44px 이상 |

---

## 2. 핵심 사용자 동선 (User Flow)

```
[랜딩/업로드] ──▶ [분석 중] ──▶ [뜸해진 거래처 대시보드] ──▶ [거래처 상세 + 문안] ──▶ [복사/내보내기]
     1클릭           자동            1클릭(행 선택)                 1클릭(문안 선택)          1클릭
```

### 2.1 단계별 설계

**Step 1. 업로드 (홈 = 업로드 화면)**
- 별도 로그인/온보딩 없이 첫 화면이 곧 업로드 영역.
- 드래그 앤 드롭 + 파일 선택 버튼 + "샘플 데이터로 체험하기" 링크(심사자/신규 사용자용).
- 지원 형식 안내: `CSV · XLSX`. 열 이름은 자동 매핑하고, 실패 시에만 매핑 화면 노출.
- 상시 문구: "파일은 이 기기에서만 처리돼요."

**Step 2. 분석 (자동, 3초 이내 체감)**
- 진행 상태는 스켈레톤 + 한 줄 안내 ("거래 내역을 읽고 있어요").
- 취소 버튼 제공. 에러 시 "다시 시도" 한 개의 버튼만 제시.

**Step 3. 대시보드 (결과 요약 → 행동 대상 선택)**
- 상단: KPI 3개 (전체 거래처 / 뜸해진 거래처 / 가장 오래 무연락).
- 중앙: **뜸해진 거래처 리스트** (기본 정렬: 마지막 거래 오래된 순 + 거래 규모 가중).
- 우측/하단: 보조 차트 1~2개 (무연락 기간 분포, 거래 추이).
- 리스트 행 전체가 클릭 영역. 행 우측에 `문안 만들기` 보조 버튼.

**Step 4. 거래처 상세 + 문안**
- 좌: 거래 이력 요약(Sparkline + 마지막 거래일 + 평균 주기).
- 우: 문안 3종(안부형 / 제안형 / 재주문 유도형) 탭, 기본값은 안부형.
- 톤 선택(정중 / 친근)은 칩 2개로 즉시 반영, 별도 모달 없음.

**Step 5. 사용**
- 주 CTA: `문안 복사` (복사 후 토스트 "복사했어요").
- 보조: `다음 거래처`(다음 행으로 이동 — 대시보드로 돌아가지 않고 연속 처리), `전체 내보내기(CSV)`.

### 2.2 동선 효율 규칙
- **돌아가기 없는 연속 처리**: 상세 화면에서 이전/다음 거래처로 이동 (키보드 `←` `→` 지원).
- **되돌아갈 곳 항상 표시**: 상단 breadcrumb `홈 › 대시보드 › 거래처명`.
- **상태 유지**: 업로드 데이터·필터·정렬은 새로고침 후에도 로컬에 유지, `초기화`는 별도 위치에 두고 확인 단계 포함.
- **빈 상태/에러 상태는 다음 행동을 안내**: 빈 화면 대신 CTA 포함 (예: "뜸해진 거래처가 없어요 → 기준 기간 바꾸기").
- **기준 기간(예: 90일) 조절**은 대시보드 상단 세그먼트(30 / 60 / 90 / 직접)로 한 번에.

## 3. 화면 구성 (Information Architecture)

```
/            업로드 (홈)
/dashboard   뜸해진 거래처 대시보드
/client/:id  거래처 상세 + 문안 생성
/settings    기준 기간 · 톤 · 언어 · 데이터 초기화 (최소화)
```

내비게이션은 **상단 바 하나** (로고 · 현재 단계 · 테마 토글 · 설정). 사이드바는 사용하지 않는다 (화면 수가 적고 동선이 선형이므로).

### 3.1 대시보드 레이아웃 (데스크톱 12-col)

```
┌──────────────────────────────────────────────────────────────┐
│ 상단 바                                                        │
├──────────────────────────────────────────────────────────────┤
│ [KPI 1]        [KPI 2: accent]        [KPI 3]                │
├───────────────────────────────┬──────────────────────────────┤
│ 뜸해진 거래처 리스트 (col 8)     │ 무연락 기간 분포 (col 4)        │
│  · 행 클릭 → 상세               │ 거래 추이 Sparkline            │
└───────────────────────────────┴──────────────────────────────┘
```
- 모바일: 1열 스택, KPI는 가로 스크롤 대신 2×2 → 1열, 리스트가 KPI 바로 아래.

## 4. 컬러 시스템 (ztd-charts 테마 토큰)

ztd-charts는 **Light / Dark** 두 테마를 제공하며 모든 색이 `--ztd-*` CSS 변수입니다. Magentify Mini는 이 토큰을 그대로 UI 전체에 사용해 **차트와 화면 색이 항상 일치**하도록 합니다. 기본 테마는 **Light**.

### 4.1 토큰 표

| 토큰 | CSS 변수 | Light | Dark | 용도 |
|------|----------|-------|------|------|
| bg | `--ztd-bg` | `#FFFFFF` | `#14171B` | 페이지 배경 |
| panel | `--ztd-panel` | `#FFFFFF` | `#14171B` | 카드 배경 |
| ink | `--ztd-ink` | `#14171B` | `#F1F3F5` | 본문·제목 |
| muted | `--ztd-muted` | `#5D6570` | `#A3ABB5` | 보조 텍스트 (AA 충족) |
| dim | `--ztd-dim` | `#B3B9C2` | `#5B636D` | 축·가이드선 (**텍스트 금지**) |
| accent | `--ztd-accent` | `#0B8FD8` | `#D6FD70` | 단 하나의 강조 (버튼·선택·핵심 수치 도형) |
| accentText | `--ztd-accent-text` | `#006DA8` | `#D6FD70` | accent를 **텍스트**로 쓸 때 |
| onAccent | `--ztd-on-accent` | `#14171B` | `#14171B` | accent 위 텍스트 |
| accent2 | `--ztd-accent2` | `#D8488C` | `#FF8CC1` | 두 번째 강조 (경고·위험 거래처) |
| accent3 | `--ztd-accent3` | `#659815` | `#38C6F6` | 세 번째 강조 (회복·긍정) |
| line | `--ztd-line` | `#E6E9ED` | `#2A2F36` | 테두리·구분선 |
| line2 | `--ztd-line2` | `#F0F2F5` | `#22272D` | 보조 구분선·트랙 |
| neutral | `--ztd-neutral` | `#D5DAE0` | `#3A414A` | 나머지 항목 채움 |
| neutralStrong | `--ztd-neutral-strong` | `#9AA3AE` | `#5F6772` | 강한 채움 |
| neutralSoft | `--ztd-neutral-soft` | `#EEF1F4` | `#262B31` | 연한 채움·스켈레톤 |
| lift | `--ztd-lift` | `#F4F6F8` | `#1D2126` | hover/focus 배경 |
| tint | `--ztd-tint` | `rgba(11,143,216,.12)` | `rgba(214,253,112,.14)` | 뱃지·선택 행 배경 |

### 4.2 Magentify Mini 의미 매핑

| 의미 | 토큰 | 사용 예 |
|------|------|---------|
| 주요 행동 | `accent` + `onAccent` | `문안 복사`, `분석 시작` 버튼 |
| 현재 선택/포커스 | `tint` 배경 + `accentText` | 선택된 거래처 행, 활성 탭 |
| 위험 (오래 무연락) | `accent2` | 180일 이상 무연락 뱃지 |
| 주의 | `neutralStrong` + `ink` | 90~179일 무연락 |
| 정상/회복 | `accent3` | 최근 재거래 |
| 비활성/그 외 항목 | `neutral` | 차트의 비강조 막대 |

### 4.3 색 사용 규칙
1. **accent는 화면당 한 영역에만** 크게 쓴다 (가장 중요한 KPI 또는 주 CTA).
2. 색만으로 상태를 전달하지 않는다 → 뱃지에 **아이콘 + 텍스트** ("⚠ 180일+").
3. 텍스트에 `dim` 사용 금지 (Light 기준 대비 1.97:1). 보조 텍스트는 `muted`.
4. accent를 텍스트로 쓸 땐 반드시 `accentText` (Light `#006DA8`).
5. 브랜드 색 변경이 필요하면 CSS 변수 한 줄로 교체: `--ztd-accent`, `--ztd-accent-text`(4.5:1 이상 유지).

### 4.4 구현 스니펫

```tsx
import { ThemeProvider } from "ztd-charts";

<ThemeProvider theme="light" locale="ko-KR" paint>
  <App />
</ThemeProvider>
```

```css
/* 앱 전역 — 토큰을 그대로 UI에도 사용 */
body { background: var(--ztd-bg); color: var(--ztd-ink); font-family: var(--ztd-font); }
.card { background: var(--ztd-panel); border: 1px solid var(--ztd-line); border-radius: var(--ztd-radius); }
.btn-primary { background: var(--ztd-accent); color: var(--ztd-on-accent); }
.row:hover { background: var(--ztd-lift); }
.row[aria-selected="true"] { background: var(--ztd-tint); }
.link, .kpi-number { color: var(--ztd-accent-text); }
```

## 5. 타이포그래피

| 항목 | 값 |
|------|-----|
| 한글/영문 본문 | `Pretendard Variable` → `Pretendard` → `Apple SD Gothic Neo` → `Noto Sans KR` → `Malgun Gothic` → system-ui (`--ztd-font`) |
| 숫자·코드 | `Roboto Mono` → `Share Tech Mono` → ui-monospace (`--ztd-mono`) |

| 역할 | 크기 / 굵기 / 행간 |
|------|--------------------|
| Display (KPI 숫자) | 40px / 700 / 1.1, `tabular-nums` |
| H1 | 28px / 700 / 1.3 |
| H2 | 20px / 600 / 1.4 |
| Body | 16px / 400 / 1.6 |
| Caption·보조 | 14px / 400 / `muted` |
| 버튼 | 16px / 600 |

- 숫자는 `font-variant-numeric: tabular-nums`로 정렬.
- 한국어는 `word-break: keep-all`로 단어 단위 줄바꿈.
- 금액·기간 포맷은 ztd-charts 로케일 포맷 사용 (`formatCompact`, `formatCurrency`, `formatDate` → "1.2만", "₩5,000", "3월 15일").

## 6. 형태·간격·모션

| 항목 | 값 |
|------|-----|
| 카드 반경 | `--ztd-radius` **18px** |
| 코드/입력 영역 반경 | `--ztd-radius-code` 14px |
| 작은 마크(뱃지 점 등) | `--ztd-radius-mark` 4px |
| 간격 단위 | 4px 기반 (4 / 8 / 12 / 16 / 24 / 32 / 48) |
| 카드 내부 패딩 | 24px (모바일 16px) |
| 그림자 | 사용 최소화, `line` 테두리로 구분 |
| 최대 콘텐츠 폭 | 1200px |

**모션**
- ztd-charts 기본 스프링(오버슈트 없음) 사용: `easing="spring"`, `duration≈900ms`, `stagger≈120ms`.
- 차트는 **화면에 들어올 때 한 번** 애니메이션 (`animateOnView`).
- UI 전환(탭·패널)은 150–200ms ease-out.
- OS의 "동작 줄이기" 설정을 따른다 (`reducedMotion="auto"`).

## 7. 컴포넌트 명세

### 7.1 업로드 존
- 큰 점선 영역(`line` 점선, 배경 `lift`), 드래그 시 `tint` + `accent` 테두리.
- 아이콘 + "거래 내역 파일을 여기로 끌어다 놓으세요" + `파일 선택` 버튼(주 CTA) + `샘플로 체험하기`(텍스트 링크).
- 하단 안심 문구 + 지원 형식.

### 7.2 KPI 카드 (`StatCard`)
- 숫자(Display) + 라벨 + 전월/기준 대비 변화.
- 핵심 KPI("뜸해진 거래처") 1개만 accent 사용.

### 7.3 거래처 리스트 (테이블)
| 컬럼 | 내용 |
|------|------|
| 거래처 | 이름 (굵게) |
| 마지막 거래 | 날짜 + "N일 전" |
| 무연락 상태 | 뱃지(아이콘+텍스트) |
| 누적 거래액 | 우측 정렬, mono 숫자 |
| 행동 | `문안 만들기` 보조 버튼 |

- 행 높이 56px 이상, 행 전체 클릭, 키보드 ↑↓ 이동 + Enter 진입.
- 상단에 검색 + 상태 필터 칩(전체 / 주의 / 위험). 필터는 최대 2개 컨트롤로 제한.

### 7.4 문안 카드
- 탭 3종 + 톤 칩 2종, 본문은 편집 가능한 텍스트 영역(16px).
- 고정 하단 바: `문안 복사`(주) · `다시 만들기`(보조) · `다음 거래처`.

### 7.5 뱃지
- `tint` 계열 배경 + 아이콘 + 텍스트, 높이 24px, 반경 `radius-mark`보다 큰 pill.

### 7.6 토스트·피드백
- 복사/내보내기 성공은 토스트(3초), 오류는 인라인 메시지 + 재시도 버튼.
- 모든 비동기 동작은 즉시 로딩 상태 표시.

## 8. 차트 사용 가이드 (ztd-charts)

| 목적 | 차트 | 비고 |
|------|------|------|
| 무연락 기간 분포 | `BarChart` 또는 `HistogramChart` | `highlight`로 90일+ 구간만 accent |
| 상태 비율 | `DonutChart` | 항목 2–4개로 제한 |
| 거래처별 거래 추이 | `Sparkline` / `LineChart` | 리스트·상세에 소형 삽입 |
| 거래 활동 달력 | `CalendarHeatmap` | 상세 화면 선택 사항 |
| 핵심 수치 | `StatCard` | 대시보드 상단 |

규칙:
- 차트 카드(`ChartCard`)에는 항상 `takeaway` 한 줄을 넣는다.
- 한 화면 차트는 최대 3개. 강조 항목은 `highlight` 하나.
- 범례 색은 `accent / ink / neutral` 순서로 일관 적용.
- 모든 차트에 `locale="ko-KR"`, 대체 텍스트(`ariaLabel`)와 숨김 데이터 표가 자동 제공됨.

```tsx
<ChartCard number="01" title="무연락 기간 분포" takeaway="90일 이상 무연락 거래처가 가장 많아요" level="basic">
  <BarChart data={rows} x="bucket" y="clients" highlight="max" locale="ko-KR" />
</ChartCard>
```

## 9. 접근성

- 본문·보조 텍스트 대비 **4.5:1 이상** (`ink`, `muted`, `accentText`만 텍스트에 사용).
- 키보드만으로 전 과정 수행 가능: Tab 순서 = 시각 순서, `Enter/Space` 선택, `←/→` 거래처 이동, `Esc` 닫기.
- 포커스 링: 2px `accent` 외곽선 + 2px 오프셋, 항상 보이게.
- 터치 타겟 최소 **44×44px**.
- 상태는 색 + 아이콘 + 텍스트 3중 전달.
- 차트는 `role="img"` + 데이터 표 대체 제공 (ztd-charts 내장).
- `prefers-reduced-motion` 존중, `prefers-color-scheme`로 초기 테마 선택(기본 Light, 토글 제공).

| 구간 | 폭 | 레이아웃 |
|------|-----|----------|
| Mobile | < 640px | 1열, 하단 고정 CTA 바, 리스트는 카드형 |
| Tablet | 640–1023px | 1열 + 2열 혼합, KPI 3열 |
| Desktop | ≥ 1024px | 12-col, 리스트 8 / 차트 4 |

- 모바일에서 테이블은 카드 리스트로 전환(거래처명·무연락일·뱃지·행동 버튼만 노출).

## 11. 카피 톤 (한국어)

- 해요체, 짧고 구체적으로. 예: "뜸해진 거래처를 찾았어요", "문안을 복사했어요".
- 전문 용어 대신 일상어: "이탈 위험" → "연락이 뜸해졌어요".
- 오류는 원인 + 해결: "파일에서 날짜 열을 찾지 못했어요. 열 이름을 확인해 주세요."

## 12. 공모전 어필 포인트

1. **업로드 한 번으로 끝나는 3클릭 동선** — 설정·가입 없음
2. **로컬 처리** — 거래 데이터가 기기 밖으로 나가지 않는 신뢰감
3. **차트-UI 토큰 통일** — ztd-charts 테마 하나로 일관된 시각 언어, 다크/라이트 즉시 전환
4. **한 화면 한 강조** — 숫자보다 결론을 먼저 보여주는 정보 설계
5. **접근성 AA** — 대비·키보드·모션 감소 대응
